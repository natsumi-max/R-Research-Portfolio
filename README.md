
# R Programming Portfolio: Longitudinal Health Data Analysis

**Author:** Natsumi Matsue  
**Institution:** University of California, Los Angeles (UCLA)

## Project Overview

This portfolio demonstrates R programming skills in data management, quality assurance, and longitudinal health data analysis using an educational hypertension study dataset.

The project was developed from coursework in BIOSTAT 203A (Data Management in Biostatistics) at UCLA and organized into a reproducible analytical workflow.

## Technical Skills Demonstrated

- Data import with explicit variable types
- Missing data assessment
- Duplicate detection and key integrity validation
- Data integration using joins
- Longitudinal data transformation
- Variable derivation and conditional logic
- Descriptive statistical analysis
- Data visualization using ggplot2
- Defensive programming and quality assurance

## R Packages

- readr
- dplyr
- tidyr
- ggplot2
- here
- rmarkdown

## Files

- `health_data_analysis.Rmd` — R Markdown source code
- `health_data_analysis.html` — Rendered analysis report
- `data/` — Educational hypertension study CSV datasets shared with instructor permission.

## How to Run

1. Open the R project in RStudio.
2. Install the required R packages if necessary.
3. Place the required CSV files in the `data/` directory.
4. Open `health_data_analysis.Rmd`.
5. Click **Knit** to generate the HTML report.

## Data Source and Acknowledgment

This project uses an educational hypertension study dataset provided for UCLA BIOSTAT 203A coursework.

The original laboratory exercises provided the instructional framework. The portfolio reorganizes and documents the analytical workflow to demonstrate practical R programming and data management skills.

## Notes

The results are intended for educational demonstration and should not be interpreted as clinical findings.
